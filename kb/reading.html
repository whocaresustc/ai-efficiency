The subagent question (multi-agent debate)

  • Don't Build Multi-Agents — Walden Yan, Cognition. The most-cited case against subagent swarms: "share context; actions carry implicit decisions" → default to single-threaded linear agents. The "con" anchor. See Agents.
  • Multi-Agents: What's Actually Working — Walden Yan, Cognition. The author's own later refinement — the narrow class of multi-agent that works (subagents contribute intelligence, writes stay single-threaded). The "then vs. now" bookend.
  • How we built our multi-agent research system — Anthropic. The canonical "pro" case for orchestrator-worker multi-agent, with real production lessons (and the 15× token cost). The direct counterpart to Cognition's skepticism.
  • When to fold subagents into your main agent loop — Diane Sarkis, Anthropic (Oct 2026). The newest, most prescriptive entry: across enterprise deployments a single agent with progressively-disclosed skills + tool search often beat both one-giant-prompt and subagent designs on quality, cost, and latency — keep subagents for verification/parallel/permissioning. Ships a migration kit. The "when to fold back" answer.

Agent engineering & technique

  • Effective context engineering for AI agents — Anthropic. Popularized "context engineering as the successor to prompt engineering" — just-in-time / compaction / note-taking. Distilled in Techniques.
  • Agentic Autonomy Levels — Addy Osmani. A reusable framework for calibrated agent autonomy and the shift from "verification by you" to "verification by evidence the agent produces."
  • Loop Engineering — Addy Osmani. "Replace yourself as the person who prompts the agent — design the system that does it instead": a recursive goal + a separate model that grades completion (the writer isn't the grader). Five building blocks, now in Claude Code (/loop, /goal) and Codex. Distilled in Techniques; mirrors this repo's own RSI loop.
  • Practical Loop Engineering — Addy Osmani (Aug 2026). The hands-on companion to the above: concrete recipes composing /schedule + /goal + skills + dynamic workflows + auto mode (e.g. "hourly, triage every new bug report until done"; "/goal: Lighthouse ≥ 90, stop after 5 tries"). Concept → practice.
  • Embracing the parallel coding agent lifestyle — Simon Willison. Crystallized running multiple coding agents in parallel (worktrees) — and named review throughput as the real bottleneck.
  • How to be more ambitious: A tutorial for humans with models — Felix Rieseberg, Anthropic. Speed/Altitude/Depth/Range framework with reusable prompts. Distilled in Techniques.

Agent security & evals

  • The lethal trifecta for AI agents — Simon Willison. Coined the reference framing for agent/prompt-injection risk: private data + untrusted content + external communication.
  • Introducing FrontierCode — Cognition. First benchmark measuring code mergeability ("would a human maintainer merge this PR?") rather than mere correctness — a shift in how agentic coding is evaluated.
