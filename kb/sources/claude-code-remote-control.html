Claude Code Remote Control

Continue a local Claude Code session from your phone, tablet, or any browser. Your code stays on your machine; only chat messages and tool I/O cross the encrypted bridge.

What it is

Remote Control turns the Claude Code process running on your laptop into something you can drive from claude.ai/code or the Claude mobile app. Unlike Claude Code on the web (which runs in cloud sandboxes), the session here is your local one: same files, same MCP servers, same project context.

Requirements

  • A Claude.ai subscription with Code access (e.g. Claude Max). Logged-in via /login in the Claude Code CLI — an ANTHROPIC_API_KEY alone is not enough.
  • A recent Claude Code CLI. Check with claude --version and update if needed: 
    claude update
  • The Claude mobile app (iOS/Android) or any modern browser.

Start a session

Option A — Start fresh

Run a dedicated Remote Control process from any project directory:

claude remote-control

Or the shorthand:

claude rc

The terminal stays in foreground showing a session URL, connection status, and tool activity. Press Space to display a QR code.

Option B — Convert an active session

Already mid-conversation? From inside Claude Code, run:

/remote-control

Or:

/rc

Your full conversation history carries over.

Tip: run /rename my-session first. A session called "sure, go ahead" is impossible to find on a phone later.

Connect from another device

  1. Mobile app (fastest): press Space in the running terminal to show a QR code, then scan it with the Claude app. The session opens in the Code tab.
  2. Browser: copy the session URL printed in the terminal and open it on any device. Useful when the app isn't installed, or to share view with a colleague.
  3. From claude.ai/code: your active Remote Control session shows up in the session list — just click it.

Don't have the app yet? Run /mobile inside Claude Code for a download QR code.

Conversation stays in sync across terminal, browser, and phone — you can send messages from any of them interchangeably.

Always-on Remote Control

To make every session a Remote Control session automatically:

  1. In Claude Code, run /config.
  2. Set Enable Remote Control for all sessions to true.

Mobile push notifications

You can ask things like "notify me when the tests finish" and get a push on your phone. To enable:

  1. Install the Claude mobile app and sign in with the same account.
  2. Allow notifications when prompted by the OS.
  3. In Claude Code, run /config and turn on push notifications.

Security model

  • The local CLI makes outbound HTTPS only. No inbound ports are opened on your machine.
  • The CLI registers with the Anthropic API and polls for work; messages are routed over a streaming TLS connection.
  • Multiple short-lived, purpose-scoped credentials are used and expire independently.
  • Files and MCP servers never leave your machine. Only chat messages and tool results cross the bridge.

Limitations

  • One Remote Control session per Claude Code instance. Run a second instance (separate terminal/dir) for a second session.
  • Several slash commands are not available remotely / behave differently — notably: /mcp, /plugin, /resume, /compact, /clear, /context, /usage, /usage-credits, /recap, /reload-plugins, /exit.
  • Auto-reconnect tolerates short network drops (~10 minutes); after that you'll need to reconnect.
  • Permission prompts still appear — you approve each action from whichever device is connected. --dangerously-skip-permissions is reportedly not honored here.

Troubleshooting

"Remote Control requires a claude.ai subscription"

You're authenticated with an API key, not a claude.ai login. Log out and re-login:

claude auth login

Make sure no ANTHROPIC_API_KEY is set in your shell — it can shadow the subscription auth.

"Remote Control requires a full-scope login token"

Your token doesn't have the right scope. claude auth login again to refresh.

"Remote Control is not enabled for your account"

Reported workaround: /logout in the CLI, then log back in. Restart the process.

API 500s after restart / phantom sessions

If a previous claude remote-control died ungracefully, existing remote clients can return mysterious errors instead of "session ended." Fully quit the mobile app / close the browser tab, restart the CLI, and reconnect.
