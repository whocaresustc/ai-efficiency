Claude Code

Parallel workflow (the core idea)

The highest-leverage habit, per creator Boris Cherny: run multiple Claudes in parallel (5+ terminal tabs, numbered), use notifications to know when one needs input, and run sessions on claude.ai/code alongside local ones — handing off with &, moving between them with --teleport.

Settings worth turning on

  • Notifications — /config → Notifications → terminal_bell, so you can multitask and get pinged when Claude needs you.
  • Fullscreen rendering — export CLAUDE_CODE_NO_FLICKER=1 for a flicker-free full-screen UI with mouse support; Ctrl+o opens a less-like transcript viewer.
  • /insights — generates an HTML usage report (what's working, friction analysis, suggested CLAUDE.md additions, workflows to try). Saved to ~/.claude/usage-data/report.html.
  • Auto memory — persistent per-project memory at ~/.claude/projects/<path>/memory/; MEMORY.md loads into every session. Store stable patterns/paths/preferences, not session context. Use /remember to save explicitly.

Git worktrees

Run parallel Claude sessions on isolated checkouts instead of switching branches in one working copy — avoids clobbering in-flight edits. Full comparison in the source note.
