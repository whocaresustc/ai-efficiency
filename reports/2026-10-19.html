Google open-sources Harness² — recursive agent harnessing that improves agents without touching model weights

Google Cloud AI Research (with Northwestern) released Harness² (arXiv 2610.14224, code at google-research/harness2, Apache 2.0), a plug-and-play framework that keeps the base model frozen and recursively edits the scaffold around it — system prompt, guardrails, memory, tool guidance, subagents, skills, scripts, and plugins — via a contrastive Propose–Probe–Compose loop that needs no ground-truth verifier. Why it matters: a single refinement step lifted GLM-5 and Gemini 3.5 Flash across WorkBuddy-Bench (+11.5pt), JobBench (+4.5pt), and Harvey's Legal bench (+11.8pt Partial) — in several cases a weaker model with a better harness beat a stronger model with its stock harness, reframing the harness as a first-class, versionable engineering surface rather than the model being the only upgrade lever.

Tier 2 arXiv 2610.14224 · github.com/google-research/harness2 Score 4

Harness²: Recursive Agent Harnessing for an Open World

Two coupled recursion loops: task-level refines the harness for the current task (parallel or sequential, budget --k), and harnessing-level accumulates evidence-backed lessons into a persistent improvement harness that transfers across tasks. Ships a credential-free local demo; model-backed runs use Gemini 3.5 Flash / GLM-5 as frozen executors under OpenCode and Codex, with Claude Opus 4.8 as the default harness editor. Why it matters: concrete, file-based, diffable implementation of harness optimization — every scaffold change is a reviewable patch, which is exactly the shape production agent teams can adopt. Note: repo states it is not an officially supported Google product.
