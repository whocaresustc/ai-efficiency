💡 为什么硅谷AI大佬最近突然都在说同一句话：「你还不够有野心」

最近刷AI圈，有个特别明显的感觉👇

从 Jensen Huang（英伟达）、Alexandr Wang（Scale AI → Meta 超级智能），到 Scott Wu（Cognition / Devin）、Aaron Levie（Box），再到写代码的大神 Simon Willison、Kent Beck——

这些平时八竿子打不着的人，最近几个月居然都在讲同一件事：

👉 「用AI别想太小了，要更有野心（be more ambitious）。」

· · ·

一开始我也有点反感😅 ——「又在贩卖焦虑？」

但看多了之后我发现，他们说的其实是同一个洞察：

🔑 The bottleneck is no longer the model.
瓶颈已经不是AI模型强不强了，而是你自己的想象力和野心。

Jensen 的原话特别戳：
「Productivity should be thought of as raising ambition」——生产力不是用来裁人省钱的，是用来做以前根本不敢想的事的。

Alexandr Wang 说得更直接：未来稀缺的不是智能、不是算力，是 vision 和 ambition（愿景和野心）🔥

· · ·

那「更有野心」到底怎么落地？我觉得 Felix Rieseberg（Anthropic） 那套框架最实用，分四个方向：

① Speed 速度：同样的事做得更快（入门款）
② Altitude 高度：别让AI「改这个bug」，让它「让整个App保持零崩溃」——给目标，不给任务
③ Depth 深度：逼它用行业顶尖专家的方法做，而且别让它自己给自己打分
④ Range 广度：一个任务拉上多个领域的「专家」一起干

· · ·

Box 的 CEO 还给了个超简单的自测标准👇

💬「If you could have done it before AI, you're not pushing hard enough.」
如果这件事你没有AI也能做，那说明你还不够大胆。

还有个细节我很喜欢：一个野心项目失败了也别删，过半年再试一次——因为模型一直在变强，上次做不到的，这次可能就成了。

· · ·

最真实的一条来自 Simon Willison，他把「be more ambitious」定成了今年的新年目标，但也老实说：

「我的活儿反而变更难了——因为简单的都被AI干掉了，剩给我的全是硬骨头。」😂

所以这事儿不是鸡汤。它的意思是：把你的下限交给AI，把你的上限拉高。
